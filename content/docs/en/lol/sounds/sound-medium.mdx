## Important

**This guide teaches how to make custom banks in a way that will work within riot games ecosystem. To basics of using wwise, use Wwise 101 linked above.**

## Bank Structure & Split Exports

League splits audio assets into two distinct files:

- `audio.bnk` / `audio.wpk`: contains **media only** (raw `.wem` audio files).
- `events.bnk`: contains the **logic hierarchy** (events, action sequences, containers, switches, and bus routing).

Wwise's hierarchy is flat—every element carries an `ID` and a `ParentID`. This makes it possible to inject new elements that attach themselves to existing parents in League's hierarchy without replacing the entire tree.

### Keep Media and Events Split
When generating SoundBanks in Wwise, you can bundle structure and media into a single bank. This is Optional, but ff you merge events and media together, other modders cannot inspect or replace your sounds in Quartz. If u wanna Split use:
1. An `_events.bnk` holding structure and event definitions.
2. An `_audio.bnk` (or `.wpk`) holding media only.

Else dump everything into `_events.bnk`

## Project Hierarchy Best Practices

Avoid placing sound objects directly beneath a Work Unit:

```
❌ Bad:
Work Unit -> Sound SFX

✅ Good:
Work Unit -> Actor-Mixer -> Random / Sequence Container -> Sound SFX

```
### Why Use Actor-Mixers?

An Actor-Mixer acts as a centralized controller for a character kit or spell group. You define defaults on the Actor-Mixer once:

* Output bus routing (`daad0rhm` for SFX)
* Attenuation sharesets
* Playback priority
* Base Make-up Gain

Child containers inherit these parameters automatically. If one sound needs special behavior, enable **Override parent** on that specific child.

### Adjust Volume with Make-up Gain

When balancing levels in Wwise, **adjust Make-up Gain rather than Voice Volume**. Voice Volume interacts with run-time faders and ducking headroom; Make-up Gain provides clean, predictable static gain staging without clipping.

### Adding Random Pitch Variation

Riot frequently applies subtle random pitch modulation to repetitive actions so they feel natural (e.g., Sett W cast variants, Grasp of the Undying procs):

1. Select your container or sound object.
2. Click the random/dice icon next to **Pitch**.
3. Set a range between `-50` and `+50` cents.

## Audio Routing: Output Buses

You cannot modify or replace existing game buses directly. However, you can route directly to existing buses or create custom child buses beneath them.

| Purpose | Bus Name |
| --- | --- |
| **Champion SFX** (Standard spell casts, impacts, and auto-attacks) | `daad0rhm` |
| **Champion VO** | `vo_champions` |
| **Announcer callouts** | `vo_announcer_default` |
| **Champion theme music** (Create a custom child bus under this) | `mus_champion` |
| **Background / Map BGM** | `mus_map` |
| **Notifications & UI audio** | `sfx_hud` |
| **Tactical pings** | `sfx_pings` |
| **Ambient and environmental sound** | `sfx_enviorment` |
| **Teamfight Tactics music** | `tft_mus_default` |

> Champion combat sounds should always route to `daad0rhm`. Wet buses run through global environmental reverb and distortion filters (such as Evelynn's passive sound distortion)—routing to `daad0rhm` keeps your SFX clear.

## Auto-Ducking Official Buses

If your custom sound needs to push down background elements (e.g., a special ultimate voice line or custom music track):

1. Route your sound through a custom child bus.
2. Under your custom bus's **Auto-Ducking** tab, add the target official bus (e.g., `mus_map`).
3. Set the target bus to duck by **Bus Volume**, **never Voice Volume**. Ducking voice volume can cause active sound instances to drop out entirely.

## Positioning & Attenuation

### Key Settings:

* **Distance Units:** Wwise distance units map directly to League in-game range units (Flash range is 400; basic ranged attacks are 500–650).
* **Disable Height Spread:** League is played on a 2D plane with an isometric camera. Always disable Height Spread in 3D positioning to prevent vertical panning glitches.
* **Replicating Official Curves:** You cannot directly reference official attenuation assets by ID. Instead, check the [League Wwise Hierarchy Reference](http://lol-wwise-hierarchy.aurecueil.uk/?utm_source=gemini) to inspect the max distance, roll-off curves, and cones used by base champions, then recreate matching curves in your project's attenuation sharesets.

## Loading Order & .bin Overrides

In League, **first loaded wins**. If two banks define the same element, the second one is silently discarded.

You configure loading order in the skin's `.bin` file:

```
bankPath: list[string] = {
    "ASSETS/Sounds/Wwise2016/VO/en_US/Characters/Yone/Skins/Base/Yone_Custom_VO_audio.bnk"  ← Custom bank loads first
    "ASSETS/Sounds/Wwise2016/VO/en_US/Characters/Yone/Skins/Base/Yone_Base_VO_audio.bnk"
    "ASSETS/Sounds/Wwise2016/VO/en_US/Characters/Yone/Skins/Base/Yone_Base_VO_audio.wpk"
    "ASSETS/Sounds/Wwise2016/VO/en_US/Characters/Yone/Skins/Base/Yone_Base_VO_events.bnk"
}

```

### Bank Naming Rules:

* **Overriding Official Events:** If you are only replacing events that already exist in the base game, your custom bank does **not** strictly need `_events` in its filename. Because the engine already registers event names from the base game bank, your bank cleanly intercepts them as long as it loads first.
* **Adding New Events:** If you are adding brand-new events that the base champion does not have, your bank file name **must contain `_events**` (e.g., `Yone_Custom_events.bnk`). League's sound loader only parses event definition tables from banks with `_events` in the filename.
* **Custom States and Switches:** Creating custom states or switches requires generating and loading an `Init.bnk`. *(Note: injecting or renaming a custom `Init.bnk` in League is experimental and unverified—prefer using existing official states and switches where possible).*

## Misc Tip: Conversion Settings

You can use custom conversion settings in your Wwise project (Vorbis compression, adjusting quality or sample rate) to significantly reduce the final file size of your exported `.bnk` and `.wem` files.
